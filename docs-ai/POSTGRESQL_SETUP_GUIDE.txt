# PostgreSQL Local Setup Guide for NIRI Backend

## 📋 Complete PostgreSQL Local Installation & Setup

यह guide आपको step-by-step बताएगा कि PostgreSQL को local machine पर कैसे install और configure करें।

## 🖥️ Operating System Wise Installation

### 1. **macOS Setup**

#### **Option A: Using Homebrew (Recommended)**
```bash
# Homebrew install करें (अगर नहीं है)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# PostgreSQL install करें
brew install postgresql@15

# PostgreSQL service start करें
brew services start postgresql@15

# PostgreSQL को system startup पर auto-start करने के लिए
brew services enable postgresql@15
```

#### **Option B: Using PostgreSQL.app (GUI)**
1. https://postgresapp.com/ से download करें
2. Install करें और start करें
3. GUI interface से database create करें

### 2. **Windows Setup**

#### **Option A: Using Installer**
1. https://www.postgresql.org/download/windows/ से download करें
2. Installer run करें
3. Password set करें (remember करें!)
4. Port 5432 select करें
5. Installation complete होने पर pgAdmin open होगा

#### **Option B: Using Chocolatey**
```powershell
# Chocolatey install करें (अगर नहीं है)
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

# PostgreSQL install करें
choco install postgresql

# Service start करें
net start postgresql-x64-15
```

### 3. **Ubuntu/Debian Setup**

```bash
# Update package list
sudo apt update

# PostgreSQL install करें
sudo apt install postgresql postgresql-contrib

# PostgreSQL service start करें
sudo systemctl start postgresql

# Auto-start enable करें
sudo systemctl enable postgresql

# PostgreSQL version check करें
sudo -u postgres psql -c "SELECT version();"
```

### 4. **CentOS/RHEL Setup**

```bash
# PostgreSQL repository add करें
sudo dnf install -y https://download.postgresql.org/pub/repos/yum/reporpms/EL-8-x86_64/pgdg-redhat-repo-latest.noarch.rpm

# PostgreSQL install करें
sudo dnf install -y postgresql15-server postgresql15

# Database initialize करें
sudo /usr/pgsql-15/bin/postgresql-15-setup initdb

# Service start करें
sudo systemctl start postgresql-15
sudo systemctl enable postgresql-15
```

## 🔧 PostgreSQL Configuration


#### **Windows:**

#### **Linux:**

### 2. **PostgreSQL Connection Test**

```bash
# Default postgres user से connect करें

```

## 🗄️ Database Setup for NIRI

### 1. **Create Database**

```sql
-- PostgreSQL में login करें
psql -U postgres

-- Database create करें
CREATE DATABASE niri_db;

-- User create करें (optional)
CREATE USER niri_user WITH PASSWORD 'niri_password123';

-- User को database access दें
GRANT ALL PRIVILEGES ON DATABASE niri_db TO niri_user;

-- Database list check करें
\l

-- Exit करें
\q
```

### 2. **Verify Database Creation**

```bash
# Database list देखें
psql -U postgres -l

# Specific database में connect करें
psql -U postgres -d niri_db

# Tables list देखें (migration के बाद)
\dt
```

## 🔐 PostgreSQL Security Setup

### 1. **Change Default Password**

```sql
-- PostgreSQL में login करें
psql -U postgres

-- Password change करें
ALTER USER postgres PASSWORD 'your_secure_password';

-- Exit करें
\q
```

### 2. **Create Application User**

```sql
-- Application के लिए dedicated user create करें
CREATE USER niri_app_user WITH PASSWORD 'app_secure_password';

-- Database access दें
GRANT ALL PRIVILEGES ON DATABASE niri_db TO niri_app_user;

-- Schema access दें
GRANT ALL ON SCHEMA public TO niri_app_user;
```

### 3. **Update .env with App User**

```env
DB_USERNAME=niri_app_user
DB_PASSWORD=app_secure_password
```

## 🔍 Troubleshooting

### Common Issues & Solutions

#### **1. Connection Refused Error**
```bash
# Check if PostgreSQL is running
# macOS:
brew services list | grep postgresql

# Linux:
sudo systemctl status postgresql

# Windows:
Get-Service postgresql*
```

#### **2. Authentication Failed**
```bash
# Check pg_hba.conf file
# macOS: /usr/local/var/postgresql@15/pg_hba.conf
# Linux: /etc/postgresql/15/main/pg_hba.conf

# Add this line for local connections:
local   all             all                                     trust
host    all             all             127.0.0.1/32            trust
```

#### **3. Database Does Not Exist**
```sql
-- Create database
psql -U postgres -c "CREATE DATABASE niri_db;"

-- Check if created
psql -U postgres -l | grep niri_db
```

#### **4. Permission Denied**
```sql
-- Grant permissions
psql -U postgres -d niri_db -c "GRANT ALL PRIVILEGES ON DATABASE niri_db TO your_username;"
```

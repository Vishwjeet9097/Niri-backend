# NIRI Backend API - Complete Environment Variables

## 📋 All Required Environment Variables

यह file में सभी required environment variables की complete list है जो NIRI Backend API के लिए needed हैं।

## 🔧 Complete .env File Template

```env
# ===========================================
# NIRI Backend API - Environment Configuration
# ===========================================

# Database Configuration
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=your_secure_password
DB_NAME=niri_db
DB_SYNCHRONIZE=false
DB_LOGGING=true

# JWT Authentication
JWT_SECRET=your-super-secret-jwt-key-minimum-32-characters-long
JWT_EXPIRES_IN=24h

# Application Settings
PORT=3000
NODE_ENV=development

# File Storage Configuration
# Option 1: Local Storage (Default)
STORAGE_TYPE=local
STORAGE_PATH_LOCAL=./uploads

# Option 2: AWS S3 Storage (Uncomment if using S3)
# STORAGE_TYPE=s3
# AWS_ACCESS_KEY_ID=your-aws-access-key-id
# AWS_SECRET_ACCESS_KEY=your-aws-secret-access-key
# AWS_REGION=us-east-1
# S3_BUCKET_NAME=your-s3-bucket-name

# Optional: Additional Configuration
# CORS_ORIGIN=http://localhost:3000
# RATE_LIMIT_TTL=60
# RATE_LIMIT_LIMIT=100
```

## 🔧 Quick Setup Commands

### 1. Create .env File
```bash
cp env.example .env
```

### 2. Generate JWT Secret
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### 3. Create Database
```sql
CREATE DATABASE niri_db;
```

### 4. Install Dependencies
```bash
npm install
```

### 5. Run Migrations
```bash
npm run migration:run
```

### 6. Start Application
```bash
npm run start:dev
```

## 🚨 Security Notes

### JWT Secret
- Minimum 32 characters
- Use random string generator
- Never commit to version control
- Different for each environment

### Database Password
- Use strong passwords
- Include special characters
- Different for each environment
- Regular rotation recommended

### AWS Credentials
- Use IAM users with minimal permissions
- Never use root account credentials
- Enable MFA if possible
- Regular credential rotation

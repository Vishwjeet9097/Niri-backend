# NIRI Backend API - Environment Setup Guide

## 📋 Complete Environment Configuration

यह guide आपको step-by-step बताएगा कि NIRI Backend API के लिए environment कैसे configure करें।

## 🔧 Required Environment Variables

### 1. Database Configuration
```env
# PostgreSQL Database Settings
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=your_secure_password
DB_NAME=niri_db
DB_SYNCHRONIZE=false
DB_LOGGING=true
```

**कहाँ मिलेगा:**
- `DB_HOST`: आपका PostgreSQL server address
- `DB_PORT`: Default PostgreSQL port (5432)
- `DB_USERNAME`: आपका PostgreSQL username
- `DB_PASSWORD`: आपका PostgreSQL password
- `DB_NAME`: Database name (niri_db)

### 2. JWT Authentication
```env
# JWT Secret Key (बहुत important!)
JWT_SECRET=your-super-secret-jwt-key-minimum-32-characters
JWT_EXPIRES_IN=24h
```

**कहाँ मिलेगा:**
- `JWT_SECRET`: आपको खुद generate करना होगा (minimum 32 characters)
- `JWT_EXPIRES_IN`: Token expiry time (24h, 7d, etc.)

### 3. Application Settings
```env
# Application Configuration
PORT=3000
NODE_ENV=development
```

**कहाँ मिलेगा:**
- `PORT`: Application port (default: 3000)
- `NODE_ENV`: Environment mode (development/production)

### 4. File Storage Configuration

#### Option A: NFS Storage (Default for NIRI)
```env
# NFS File Storage - ensure /neibackend is mounted before starting
STORAGE_TYPE=local
STORAGE_PATH_LOCAL=/neibackend
```

**कहाँ मिलेगा:**
- `STORAGE_TYPE`: "local" set करें (NFS uses local strategy with mounted path)
- `STORAGE_PATH_LOCAL`: NFS mount path (/neibackend for NIRI)

#### Option B: AWS S3 Storage
```env
# AWS S3 Storage
STORAGE_TYPE=s3
AWS_ACCESS_KEY_ID=your-aws-access-key-id
AWS_SECRET_ACCESS_KEY=your-aws-secret-access-key
S3_REGION=us-east-1
S3_BUCKET_NAME=your-s3-bucket-name
```

**कहाँ मिलेगा:**
- `AWS_ACCESS_KEY_ID`: AWS Console → IAM → Users → Access Keys
- `AWS_SECRET_ACCESS_KEY`: AWS Console → IAM → Users → Access Keys
- `S3_REGION`: AWS region (us-east-1, ap-south-1, etc.)
- `S3_BUCKET_NAME`: आपका S3 bucket name

## 🚀 Step-by-Step Setup

### Step 1: Create .env File
```bash
# Project root directory में
cp env.example .env
```

### Step 2: Configure Database
```bash
# PostgreSQL install करें (अगर नहीं है)
# Ubuntu/Debian:
sudo apt-get install postgresql postgresql-contrib

# macOS:
brew install postgresql

# Windows:
# PostgreSQL installer download करें
```

### Step 3: Create Database
```sql
-- PostgreSQL में login करें
psql -U postgres

-- Database create करें
CREATE DATABASE niri_db;

-- User create करें (optional)
CREATE USER niri_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE niri_db TO niri_user;

-- Exit
\q
```

### Step 4: Update .env File
```env
# Database
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=your_password
DB_NAME=niri_db
DB_SYNCHRONIZE=false
DB_LOGGING=true

# JWT
JWT_SECRET=your-super-secret-jwt-key-minimum-32-characters-long
JWT_EXPIRES_IN=24h

# Application
PORT=3000
NODE_ENV=development

# File Storage (NFS)
STORAGE_TYPE=local
STORAGE_PATH_LOCAL=/neibackend
```

### Step 5: Install Dependencies
```bash
npm install
```

### Step 6: Run Database Migrations
```bash
npm run migration:run
```

### Step 7: Start Application
```bash
npm run start:dev
```

## 🌐 AWS S3 Setup (Optional)

### Step 1: Create AWS Account
1. AWS Console में जाएं
2. Account create करें
3. IAM service में जाएं

### Step 2: Create IAM User
1. IAM → Users → Create User
2. User name: `niri_dev-backend-user`
3. Programmatic access enable करें
4. Attach policies: `AmazonS3FullAccess`

### Step 3: Create S3 Bucket
1. S3 → Create Bucket
2. Bucket name: `niri_dev-backend-files`
3. Region select करें
4. Public access block करें

### Step 4: Configure CORS
```json
[
    {
        "AllowedHeaders": ["*"],
        "AllowedMethods": ["GET", "PUT", "POST", "DELETE"],
        "AllowedOrigins": ["*"],
        "ExposeHeaders": []
    }
]
```

### Step 5: Update .env
```env
STORAGE_TYPE=s3
AWS_ACCESS_KEY_ID=your-access-key
AWS_SECRET_ACCESS_KEY=your-secret-key
S3_REGION=us-east-1
S3_BUCKET_NAME=niri_dev-backend-files
```

## 🔍 Troubleshooting

### Common Issues

#### Database Connection Error
```bash
# Check PostgreSQL service
sudo service postgresql status

# Check database exists
psql -U postgres -l | grep niri_db

# Test connection
psql -U postgres -d niri_db -c "SELECT 1;"
```

#### File Upload Issues
```bash
# Check NFS mount and upload directory
ls -la /neibackend

# Check NFS is mounted
mount | grep neibackend

# Check permissions (if needed)
chmod 755 /neibackend

# Check AWS credentials (if using S3)
aws s3 ls
```

#### JWT Token Issues
```bash
# Check JWT_SECRET length
echo $JWT_SECRET | wc -c

# Should be minimum 32 characters
```

### Environment Validation
```bash
# Check all environment variables
node -e "
const config = require('./src/config/database.config');
console.log('Database config:', config);
"
```

# Submission API Postman Testing Guide

Base URL: http://<your-server-url>/submission
Authorization: Bearer <JWT_TOKEN>

---

Create Submission
Method: POST
URL: /submission
Headers:
  - Authorization: Bearer <JWT_TOKEN>
  - Content-Type: multipart/form-data
Body (form-data):
  - submission (text): JSON string of submission object
    Example: {"submissionId":"SUB-2025-123","formData":{"infraEnablers":{}}}
  - files (file): Choose file from local system
    Fieldname should match nested path in DTO. Example: infraEnablers.section4_2.file

Example: 
Key: submission
Value: {"submissionId":"SUB-2025-123","formData":{"infraEnablers":{}}}

Key: infraEnablers.section4_2.file
Value: Choose File
